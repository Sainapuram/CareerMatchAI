# CareerMatchAI

CareerMatch AI is a privacy-aware career recommendation and skill-gap analysis platform designed to help students and early-career job seekers make informed career decisions.

The platform aims to analyze résumé skills, recommend suitable career paths using O*NET occupational data, identify missing skills, suggest relevant certifications, and connect users with opportunities from official company career sources.

## Current Progress

- Explored O*NET occupational datasets.
- Integrated occupational information using O*NET-SOC codes.
- Created structured occupation profiles.
- Developed preliminary career-matching notebooks.

## Planned Features

- Résumé upload and privacy filtering
- Skill extraction
- Career recommendations
- Skill-gap analysis
- Certification recommendations
- Relevant job opportunities
